# CaféMenu — Electronic Restaurant Menu

نسخة أولية لمنيو إلكتروني تعمل على GitHub Pages.

## التشغيل
افتح `index.html` محلياً أو ارفع الملفات إلى مستودع GitHub وفعّل GitHub Pages.

## الملفات
- `index.html` الواجهة
- `style.css` التصميم
- `script.js` المنتجات والسلة

## الخطوة التالية
ربط المنتجات والطلبات بـ Firebase وبناء لوحة تحكم للمطعم.
